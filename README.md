## About

FAS-HRM is a simple solution for employee data handling, leave, payroll, gratuity & appraisal management. Employees can easily track their daily time logs & leave and managers can monitor everything easily. It can save a lot of time for you and your employees.

## Steps
<ol>
    <li>Clone the repository</li>
    <li>Create new branch & work on that[ Don't use main branch for work,commit & push ]</li>
    <li>Rename env.example to .env</li>
    <li>Change/Add database credentials in .env file</li>
    <li>Run composer update</li>
    <li>Run the migration & seed</li>
    <li>Run the server</li>
</ol>
